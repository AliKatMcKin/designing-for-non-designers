# Designing for Non-Designers: A Self-Check Questionnaire

A one-page reference handout created for a Tableau visualization standards 
session presented to the City of Tacoma cross-departmental Tableau Users Group 
in July 2023.

The checklist covers five areas analysts can review before publishing a dashboard:

- Reduce Visual Clutter
- Curate Colors Carefully
- Leave Space Between
- Check Your Alignment
- Standardize Typeface & Size

Created to give analysts a fast, independent way to assess accessibility and 
design quality without needing a design background.
